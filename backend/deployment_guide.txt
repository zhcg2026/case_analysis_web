# 服务器部署命令指南

## 1. 安装必要的Python依赖
```bash
pip3 install pymysql SQLAlchemy pandas python-docx
```

## 2. 启动后端服务（后台运行）
```bash
# 进入backend目录
cd /path/to/backend

# 后台启动服务
nohup python3 app.py > backend.log 2>&1 &
```

## 3. 检查后端服务状态
```bash
# 查看进程是否运行
ps aux | grep python3 | grep app.py

# 测试API是否正常
curl -X GET http://localhost:5000/api/auth/check
```

## 4. 前端构建
```bash
# 进入frontend目录
cd /path/to/frontend

# 安装依赖
npm install

# 构建项目
npm run build
```

## 5. 检查前端构建结果
```bash
ls -la dist/
```

## 6. 复制前端文件到Nginx目录
（根据实际服务器配置调整路径）
```bash
# 示例：复制到默认Nginx目录
sudo cp -r dist/* /usr/share/nginx/html/

# 或者复制到自定义目录
sudo cp -r dist/* /path/to/your/webroot/
```

## 7. 重启Nginx（如果需要）
```bash
sudo systemctl restart nginx
```

## 8. 查看服务运行状态
```bash
# 查看端口占用情况
netstat -tlnp | grep -E '5000|80'

# 查看防火墙状态（如果有）
sudo firewall-cmd --list-all
```

## 9. 查看日志
```bash
# 查看后端日志
cat backend.log

# 查看Nginx日志（如果需要）
sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log
```

## 10. 停止服务（如果需要）
```bash
# 查找并停止后端服务
ps aux | grep python3 | grep app.py | awk '{print $2}' | xargs kill -9
```

## 11. 数据库相关命令
```bash
# 查看数据库连接状态
docker exec -it mysql-case-analysis mysql -uroot -p'MySql@2024!Root' -e "SHOW DATABASES;"

# 查看业务平台表结构
docker exec -it mysql-case-analysis mysql -uroot -p'MySql@2024!Root' case_analysis -e "DESCRIBE business_platforms;"

# 查看业务平台数据
docker exec -it mysql-case-analysis mysql -uroot -p'MySql@2024!Root' case_analysis -e "SELECT * FROM business_platforms;"
```
